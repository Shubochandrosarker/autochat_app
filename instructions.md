# AutoChat local setup

1. Install Node.js 20 LTS or newer.
2. Open a terminal in the project directory.
3. Run `npm ci`.
4. Create `.env.local` and set:

```env
LIVEAVATAR_API_KEY=your_liveavatar_api_key
LIVEAVATAR_AVATAR_ID=513fd1b7-7ef9-466d-9af2-344e51eeb833
BILLING_API_BASE=https://adhdtoolsdaily.com/wp-json/adhd/v1
BILLING_API_BEARER=your_server_to_server_bearer
```

Never commit `.env.local`, and never use `NEXT_PUBLIC_` for either secret.

Start locally with:

```bash
npm run dev
```

Open `/embed?token=PURCHASE_TOKEN` using a token generated by the WordPress
WooCommerce flow. A session is allowed only when the billing service verifies
the token. The app then keeps the server-side session ledger alive with
heartbeats; the browser never writes or decrements the balance itself.

Before publishing, run `npm run lint`, `npx tsc --noEmit`, and `npm run build`.
Production deployment uses the existing Vercel Git integration; no GitHub
Actions workflow is required.
